Add an experimental compact tool activity view to the chat transcript. Runs of consecutive tool calls and thoughts stay summarized in one stable row such as "6 tools used" while work is live, then open on user click to show the original reasoning and tool cards in one flat list. The summary keeps the spinner, shimmer, animated count, and smooth status transitions from the working indicator without changing transcript height during streaming. Enable it under Settings, Experimental, Compact Tool Activity.
