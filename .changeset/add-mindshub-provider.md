Add MindsHub as a built-in provider. MindsHub (https://mindshub.ai) is an OpenAI/Anthropic-compatible inference gateway that reaches Claude, GPT, Kimi, DeepSeek, and other catalog models through one API key. Set `MINDSHUB_API_KEY` and select a `mindshub/<alias>` model to use it.
