Let Kilo choose the browser, device emulation, viewport, and headless mode for Playwright browser automation from the conversation. Pick the browsers it may use (Chrome, Chromium, Edge, Firefox, or WebKit) under Settings → Web Tools → Allowed Browsers, where you can also see which are installed and how much space they take. Enabling a missing Playwright build downloads it. The browser now starts only when a task needs one. The Integrated Browser's `browser_open` tool also accepts a width and height, so the agent can check responsive layouts at phone, tablet, and desktop sizes.
