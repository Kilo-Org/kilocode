Add a right-click menu to the chat session with actions you previously had to hunt for: stop the running turn, toggle auto-approve, compare the branch against its base, open the pull request in your browser, copy the pull request reference or the session id, and share the session. A new "more" button on the prompt bar gives quick access to auto-approve and sharing without right-clicking. Sharing creates a public link to the conversation, copies it to the clipboard, and offers to open it; sharing can be revoked from either menu. The pull request actions now also work in Agent Manager worktree session tabs, which previously had no branch actions at all.
