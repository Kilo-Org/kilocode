Add a right-click menu to the chat session with the actions you previously had to hunt for: stop the running turn, toggle auto-approve, create or move to a worktree, compare the branch against its base, open the pull request in your browser, copy the pull request reference or the session id, and share the session. Sharing creates a public link to the conversation, copies it to the clipboard, and offers to open it; sharing can be revoked from the same menu. The worktree and pull request actions now also work in Agent Manager worktree session tabs, which previously had no branch actions at all.
