Publish the CLI as a `kilo-cli` conda package on Anaconda.org, built with rattler-build for linux-64, linux-aarch64, osx-64, osx-arm64, and win-64 on every release (pre-releases publish to the `rc` label). Install with any conda-compatible package manager (e.g. `pixi add kilo-cli` or `conda install -c anaconda-cloud kilo-cli`).
