Legacy custom modes now migrate to the same permission keys the CLI reads: only a command group grants shell commands, a browser group grants the Integrated Browser tool of the VS Code client, an MCP group grants the tools of each migrated server, and a file restriction becomes a wildcard glob that keeps the files it allowed. A migrated mode's MCP grant and the CLI's own MCP tool ids come from one definition, so the grant always names the tools the CLI registers and a server name outside the Basic Multilingual Plane yields the same key in the CLI and the plugin, and the grant covers every server the loader that ran the migration converted rather than only the ones a project file declared. A file restriction that alternates at the top level keeps the files of every alternative. A file restriction made only of digits is reported and asks instead of denying the allowed files, one whose translated arm resolves against the home directory is reported and asks, one that escapes a character the glob cannot carry literally, including backslash, `*` and `?`, is reported and asks, so the migrated rule always means what the legacy pattern meant, a migrated mode in the CLI keeps the default skill permission because no legacy group governs it, the JetBrains migration denies skill and states that in its report, and an MCP group is reported when a skipped store declared a server the migration can grant and that no converted server's permission key covers, even when other servers were migrated, while a disabled entry, a local entry with no command and a remote entry with no url are not reported. An empty alternative matches the empty string. A pattern whose empty alternative is its whole body matches every path; when the alternative sits inside a longer pattern, it matches that pattern's surrounding characters instead. With both anchors the empty alternative is dropped so the alternatives that name a path survive, and a pattern whose every alternative is empty is reported and asks. A mode that lists the same group more than once keeps the narrower rule and reports the repeat in the migration warnings when the rule differs. With auto-approval on and no command lists, the migration grants shell commands and leaves other tools at their defaults. A mode that writes a group with its options in flow style keeps the file restriction that group names, and a group whose options arrive as their own entry asks instead of widening to every file. A single-quoted scalar decodes a doubled quote to one quote, and a `#` after it stays part of the value instead of starting a comment.
