Sign in to remote MCP servers from JetBrains. MCP Settings now shows the real sign-in error, lets you cancel an in-progress sign-in, and offers a copyable authorization URL when a browser cannot be opened automatically. Installing an MCP server from the Marketplace that needs sign-in now offers to start it right away, and the prompt toolbar shows an indicator when a configured MCP server needs sign-in. Remote MCP servers that require a pre-registered OAuth client can now be configured directly from the edit dialog.
