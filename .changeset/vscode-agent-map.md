Add an agent map that shows every subagent and Agent Manager session a session started, and their background processes, with avatars, live status, run time, and token use. Agents from reverted turns leave the map once they stop. The agent map button above the prompt replaces the background agent stack and the board button: it counts running agents and opens the map, where you can stop agents, hide finished work, and read, refresh, or reset the shared agent board in its own tab.
