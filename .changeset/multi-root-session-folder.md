Support multi-root VS Code workspaces beyond the first folder. Pick the workspace folder new sessions work in from the folder menu in the prompt bar, and see which folder each session belongs to in the session header and history. Settings can edit the project configuration and codebase indexing of any workspace folder. Code actions, editor context and file links resolve files in every folder, and inline autocomplete now works in all folders. Single-folder workspaces are unchanged.
