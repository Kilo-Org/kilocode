Add Response Lens for completed assistant responses: annotate selected text or explain it briefly without changing the prompt. Save an explanation level and optional alternate model in Kilo settings. Explanations use bounded chat context and excerpts from selected files and public links, with sensitive-path and network checks.

Annotations have durable conversation-scoped numbers and source markers; edits preserve numbers and deletion does not reuse them. New-note editors keep the pending list collapsed. Theme-aware controls improve light, dark, and high-contrast readability. A failed send can restore the composed annotation block as editable Markdown.
