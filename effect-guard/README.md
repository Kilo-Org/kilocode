# effect-guard

Детерминированный guard для ИИ-кодинг-агентов: судит **наблюдаемые эффекты**
действия, а не текст команды.

Ядро варианта 1b по кейсу «Безопасный auto mode для ИИ-кодинг-агентов».

## Требования

- **Node.js 22+** — [nodejs.org](https://nodejs.org) (LTS-установщик под Windows)
- **Git** — [git-scm.com](https://git-scm.com) (в установщике оставьте
  «Git from the command line»)

WSL **не нужен**: код кроссплатформенный, тесты проходят на Windows.

## Запуск

```bash
npm install     # ставит tsx и typescript локально
npm test        # 78 тестов
npm run demo    # end-to-end сценарий атаки
npm run typecheck
```

В PowerShell команды те же. Если `npm` не найден — перезапустите терминал
после установки Node.

## Что внутри

| Файл | Роль |
|---|---|
| `src/effects.ts` | Модель эффектов — единый тип для декларации и наблюдения |
| `src/normalize.ts` | Команда → эффекты. Fail closed: непонятое ≠ разрешённое |
| `src/invariants.ts` | Детерминированные правила. **Injection-proof слой** |
| `src/policy.ts` | Политика: protected paths, egress, авто-исполняемые артефакты |
| `src/paths.ts` | Канонизация путей (posix-форма на всех ОС) |
| `src/observe.ts` | Staged-снимок и дифф через временный git-индекс |
| `src/guard.ts` | Точка входа + Recovery с санитизацией |
| `src/packages.ts` | Package gate: slopsquatting и typosquatting |
| `src/registry.ts` | Клиент реестров: только числа и флаги, без текста |
| `src/popular.ts` | Локальный список популярных имён |

## Почему слой инвариантов неуязвим к prompt injection

На вход `evaluate()` приходит массив `Effect` — структуры с видом операции,
канонизированным путём, хостом, именем пакета. Ни одна строка на этом уровне
не интерпретируется как инструкция: нет LLM, нет шаблонов, нет исполнения.
Текст атакующего может стать *значением* поля `path`, но не может изменить
*правило*. Ослабить проверку можно только через `Policy`, а она грузится
только из доверенного места вне workspace.

## Известные ограничения

- Симлинки не резолвятся на этапе декларации (ловятся на этапе наблюдения).
- `normalize.ts` — консервативный разбор, не полный парсер bash;
  кандидат на замену — tree-sitter-bash. Интерфейс при этом не меняется.
- Внешние необратимые эффекты (прод-БД, платежи) нельзя выполнить «начерно» —
  для них остаётся детерминированный allowlist / ask.
- `node_modules` исключён из снимка ради latency — размен вынесен в бенчмарк.
- Отравленная декларация агента не даёт жёстких гарантий; жёсткие гарантии
  даёт только слой инвариантов.
