# In-app browser

Browse the web in a panel next to your chat, so you can check documentation, dashboards, or search results without switching to a separate application.

Type a URL and press Enter to load a page -- you can leave off `https://` and it's added for you. Only HTTP and HTTPS pages are supported. The panel has the controls you'd expect from a browser:

- **Back**, **forward**, and **refresh**.
- A menu with **Hard reload** and **Open DevTools**.
- **Zoom** from 25% to 500%, with a reset.

You can open more than one browser tab at a time. Each keeps its own page as you switch between tabs, and its tab label and icon update to match the site you're on.
