# Features

Kilo Desktop's capabilities appear alongside your chat, scoped to the workspace you're working in. Explore each one:

- [Notebooks](/docs/desktop/features/notebooks) — analyze data in interactive Python notebooks.
- [In-app browser](/docs/desktop/features/browser) — browse the web next to your chat.
- [Terminal](/docs/desktop/features/terminal) — run commands in an interactive shell.
- [Git integration](/docs/desktop/features/git) — review changes and switch branches.
- [Local inference](/docs/desktop/features/local-inference) — run models on your own machine.
- [Conda environments](/docs/desktop/features/environments) — manage conda environments and packages.
- [Files](/docs/desktop/features/files) — browse and edit workspace files.

Kilo Desktop also connects to the [Anaconda Remote MCP server](https://anaconda.com/docs/anaconda-mcp/main) so Anaconda tools, such as package search, are available in your chats.
