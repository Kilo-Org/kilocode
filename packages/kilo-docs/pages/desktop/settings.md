# Settings

Kilo Desktop's settings are organized into sections. This page covers the settings you'll use most.

## Accounts and authentication

Kilo Desktop uses two independent sign-ins:

- **Kilo account** -- Sign in from the account area in the sidebar to connect the app to the [Kilo Gateway](/docs/gateway) and use hosted models.
- **Anaconda account** -- Sign in with your Anaconda account to unlock the downloadable model catalog for [local inference](/docs/desktop/features/local-inference) and the [Anaconda MCP](https://anaconda.com/docs/anaconda-mcp/main) connection.

The two accounts are separate; you can use one without the other.

## AI providers

The **AI Providers** section manages where chat models come from. Connect the Kilo Gateway, add API keys for direct providers, or configure a custom endpoint. For details on the gateway itself, see [Models & Providers](/docs/gateway/models-and-providers).

## Local model server

The **Local Model Server** section controls models that run on your machine. Turn the server on or off, browse and download models from the catalog, import GGUF files, and manage installed models. See [Local inference](/docs/desktop/features/local-inference) for how local models appear in chats.

## Environments

When enabled, the **Environments** section manages conda environments and packages. See [Environments](/docs/desktop/features/environments).

## Appearance

The **Appearance** section controls the app's theme.
