Generate a new image from a text prompt or edit an existing image using the configured custom Images API, Kilo Gateway, or OpenRouter.

Usage notes:
  - Provide a `prompt` describing what to generate or how to edit
  - Provide a `path` (relative to the workspace) where the resulting image should be saved — the extension is auto-appended (.png/.jpg) if missing
  - Optionally provide an `image` path to an existing image to edit or transform (custom endpoints support PNG/JPEG; Kilo Gateway and OpenRouter also support GIF/WEBP)
  - For multiple references, provide `images` with up to 10 ordered workspace paths instead of `image`. Describe each reference's role in the prompt; the server receives them in that order.
  - The tool writes the image to disk and returns it inline in the chat
