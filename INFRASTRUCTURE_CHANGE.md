# Infrastructure Change Review: Upstream Merge PR 12695

Review range: base `70eeaff3837e29529e26c7c090767df0a3768249` to head `518501a994bcd660e8c6d061b450c32412104004` (current `HEAD`). The range contains 1,502 changed files, 118,630 insertions, and 72,565 deletions.

## Findings

1. **High: Kilo docs-sync hardening and throughput controls were removed.** Files: `.github/workflows/docs-sync.yml`, `.github/docs-sync/{edit,triage,lib,selftest}.mjs`, deleted `.github/docs-sync/redact-stream.mjs`. The job timeout falls from 240 to 120 minutes; explicit 90-minute triage and 120-minute edit budgets revert to 35/50-minute defaults; all `kilo run --auto` flags and the guarded fix pipeline are removed; full stderr artifacts, ANSI stripping, environment-secret redaction, stream redaction, and their self-tests are removed. The fix pipeline can now abort before re-verification under `set -o pipefail`, and raw child output can enter logs/artifacts without Kilo's defense-in-depth redaction. **Human verification required:** restore Kilo's security/reliability customizations unless the CLI permission model and logging policy have deliberately changed and the shorter budgets are now sufficient.

2. **High: release state was rolled back from Kilo 7.4.17 to 7.4.16.** Files: root `package.json`, 28 existing package manifests (including CLI, SDK, plugin, VS Code, UI, Kilo packages, and upstream-merge tooling), plus new upstream package manifests; `packages/{opencode,kilo-vscode,kilo-jetbrains}/CHANGELOG.md` remove unreleased/released 7.4.17 or 7.5.0 sections. The changeset directory also deletes 15 pending Kilo changesets and adds 23 others. This can republish or omit release content and breaks the expected monotonic release state. **Human verification required:** reconcile versions, changelogs, and pending changesets against Kilo's release source of truth before any release workflow runs.

3. **High: the root release pipeline now publishes `@opencode-ai/ui`.** Files: `script/publish.ts`, `packages/ui/{package.json,LICENSE,tsconfig.build.json}`, new `packages/ui/script/{pack,publish}.ts`. Every root publish run now builds declarations, tests, packs, and publishes the public upstream-named UI package with `Script.channel`; the manifest adds public publish metadata and Kilo repository metadata. This expands Kilo's release surface, credentials usage, and failure modes. **Human verification required:** decide whether Kilo owns and is authorized to publish `@opencode-ai/ui`; otherwise remove it from Kilo's release pipeline.

4. **High: stable CLI publishing no longer maintains the `rc` dist-tag.** Files: `packages/opencode/script/{publish.ts,kilocode/npm-publish.ts}`. `NpmPublish.aliases()` and `npm dist-tag add ... rc` are removed, so a stable `latest` publish no longer advances Kilo's `rc` alias. **Human verification required:** confirm this intentional channel policy change; otherwise preserve Kilo's alias behavior around the upstream publish logic.

5. **Medium: active CI now enforces a second generated client.** Files: `.github/workflows/test.yml`, `.prettierignore`, new `packages/client/**` and `packages/httpapi-codegen/**`. The HttpApi job runs `bun run check:generated` in `packages/client`, generation emits committed Promise and Effect clients, and formatting ignores both output trees. This is a new CI gate and code-generation toolchain, not merely product code. **Human verification required:** confirm Kilo wants this upstream client as committed generated output, that the check is affordable in the HttpApi job, and that Kilo-specific protocol changes regenerate deterministically.

6. **Medium: the existing SDK generation pipeline and committed output changed substantially.** Files: `packages/sdk/js/script/build.ts`, `packages/sdk/js/{package.json,openapi.json}`, `packages/sdk/openapi.json`, `packages/sdk/js/src/v2/gen/**`. Generation now prunes unreachable duplicate session schemas, patches session-history query types from strings to numbers, verifies duplicate variants, and keeps the existing Kilo patches; generated OpenAPI and TypeScript output are broadly regenerated. `packages/sdk/js/openapi.json` is newly committed and `./v2/types` becomes public. **Human verification required:** run the canonical SDK regeneration/check, review the manual post-generation replacements for brittleness, and confirm which of the two OpenAPI documents is authoritative.

7. **Medium: workspace topology and Turbo orchestration expanded.** Files: root `package.json`, `bun.lock`, `turbo.json`; new package/build configs under `packages/{client,httpapi-codegen,protocol,schema,sdk-next,session-ui}`; related dependency edges in `packages/{core,llm,opencode,server,storybook,ui,plugin}/package.json`. Bun's `packages/*` workspace now automatically includes six new upstream packages, and Turbo adds build prerequisites for core/session-ui tests. The lockfile changes by 216 additions and 42 removals. **Human verification required:** confirm all new private upstream packages belong in Kilo's workspace, CI/cache graph, source distributions, and license/security scanning.

8. **Medium: dependency patch infrastructure changed.** Files: root `package.json`, `bun.lock`, `patches/{effect@4.0.0-beta.83,@modelcontextprotocol%2Fsdk@1.29.0,@tanstack%2Fvirtual-core@3.17.0}.patch`. Effect moves from beta 74 to beta 83 and gains a new OpenAPI/SSE schema patch; MCP OAuth/refresh-token and reconnect patches expand; virtualizer behavior gains scroll-range clamping. These patches modify installed dependency artifacts and can fail during install after dependency updates. **Human verification required:** verify patch ownership, upstream status, and clean `bun install` application on supported platforms.

9. **Medium: generated database migration output is now formatted through Prettier.** Files: `packages/core/script/migration.ts`, `packages/httpapi-codegen/package.json`. Migration, schema, and registry generation/checks dynamically import Prettier's TypeScript and ESTree plugins. Existing generated files may become stale under the new byte-for-byte check. **Human verification required:** regenerate/check core migrations and confirm the formatter version/options are Kilo's desired canonical format.

10. **Medium: issue automation behavior drifted, including disabled Kilo workflows.** Files: `script/github/close-issues.ts`; `.github/workflows/disabled/{compliance-close,duplicate-issues,triage}.yml.disabled`; `.github/ISSUE_TEMPLATE/config.yml`. Team, owner/member, and `opencode-agent[bot]` authors become exempt from stale-close/compliance/duplicate/triage automation, and the support link wording changes. The stale-close script still targets `anomalyco/opencode`, while its only workflow reference is disabled. **Human verification required:** confirm Kilo's exemptions, bot identity, `TEAM_MEMBERS` trust model, target repository, and whether disabled workflows are archival only or expected to be re-enabled.

11. **Low: disabled Storybook CI and local Storybook build infrastructure expanded for `session-ui`.** Files: `.github/workflows/disabled/storybook.yml.disabled`, `packages/storybook/{package.json,.storybook/main.ts,.storybook/preview.tsx,.storybook/playground-css-plugin.ts}`, new `packages/session-ui/**`. Storybook now scans and builds session-ui stories, allows additional filesystem roots, and its development POST endpoint can write CSS in either UI package. **Human verification required:** confirm the broader write surface is acceptable for local tooling and update/enable Kilo's visual infrastructure only intentionally.

12. **Low: generated SDK output introduces widespread whitespace drift.** File: `packages/sdk/js/src/v2/gen/sdk.gen.ts`. `git diff --check` reports hundreds of trailing-whitespace lines in this generated file. **Human verification required:** determine whether this is expected generator output or a stale/unformatted generation; do not normalize manually if regeneration owns the file.
