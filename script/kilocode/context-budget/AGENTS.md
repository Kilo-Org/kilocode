# First-request context ratchet

Fix regressions at the source. Use on-demand discovery for new actions and a skill for workflow guidance. You may lower the token ceiling after measuring a reduction or remove an allowlist entry when a tool is no longer direct.

Do not raise `maxInputTokens`, add a name to `directTools`, or weaken the measurement or CI step to pass a check without explicit approval from a human maintainer. Before editing, report the tool names and before/after token counts, explain why discovery is insufficient, and wait for approval. A request to fix CI is not approval for an exception.
